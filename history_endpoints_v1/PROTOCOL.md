# 历史终点追加实验 v1

在原 B/C/D 队列结束后，追加一个 ETP 条件、三个种子，从头训练。原协议及运行记录保持不变。

## 固定条件

- 基础组：`C2_current_phase_control`，即当前控球段关系的匹配随机对照。
- 选择理由：追加登记时，在已完成三个 seed 的条件中，对抗修正验证 Event 准确率均值最高，为 68.387789%。选择已固定，不在等待期间重新挑选。
- 历史选择：复用原三个选择种子的文件，每个样本最多 16 条，候选范围 80；不因新增终点改变所选事件。
- 唯一新增输入：所选历史事件的终点 x/y 及其有效性。
- 锚点：保留起点；终点 x/y 置零，终点有效性为假；不提供由锚点终点计算的位移或其他派生信息。
- 坐标：历史终点使用各事件执行球队转换到锚点球队进攻方向，与起点相同。
- 缺失、未知球队、padding 的终点无效。依据现有占位审计，子类型 21、23、25、27、33、50、51、100 及 Offside 的终点无效。混合类型不按角落坐标一刀切，保留原始有效记录并报告数量。
- 动作输入使用 Raw10，保留原组已有的子类型槽位。所有 tags 均不进入模型、选择器或控球分组。`Pass + assist(301)/keyPass(302)` 仍为 Raw10 Pass，原始十类目标中的类别索引仍为 7；不删除该条事件，不增设助攻或关键传球类别。
- ETP 的目标、mask 和损失不变；不增加终点预测任务。

## 模型与训练

沿用基础组的公共注意力骨干与全部参数。历史终点由一个无 bias 的 `Linear(3,64)` 编码，并加到事件表示；增加 192 个参数，报告该容量变化。新增层在全部公共参数初始化后创建，保证同 seed 的公共参数与基础组一致。

种子为 20260715、20260716、20260717，学习率为 0.0027。沿用 batch 256、Rotate 128、FP32、每四轮完整验证、两次平台期衰减和最多 120 轮。按最低逐记录验证 ETP 损失选模，从头初始化，不续训原检查点。此处“一轮追加实验”指完整训练这一组，不是仅训练一个 epoch。

## 验收

- 任意修改锚点／未来事件终点，不改变当前输入或预测。
- 历史有效终点可进入输入；未选事件终点不进入输入。
- 锚点终点数值、有效性标记和 padding 均完全屏蔽。
- 对方终点按 `1−xy` 换算；未知球队与占位终点无效。
- 增删 301/302 不改变输入、Raw10 或 Pass 目标；原目标、mask 和样本顺序与基础组完全对齐。
- 同 seed 公共参数相同；前向、梯度和 batch256 更新有限；保存加载后预测一致。

## 产物与解释

独立保存终点表、验收、完整运行配置、学习曲线、检查点、逐样本预测及比赛统计。完成后与原组同 seed 配对比较，分别报告逐记录、对抗修正及非成对对抗口径；使用 10,000 次比赛聚类 bootstrap 的描述性 95% 区间。

这是根据已有验证结果选组后的探索性追加，不并入原 24 项主检验族，不宣称独立确认。测试集保持关闭；不增加 NMSTPP、Seq2Event、LEM 或其他组重跑。
